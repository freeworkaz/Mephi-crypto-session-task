# Задания

 

Развернуто и последовательно ответьте на вопросы. Отчет с ответами прикрепите в форму проверки.

Ответ на каждый теоретический вопрос (1-4) должен быть развернутым, связным и содержать четкие определения. Избегайте односложных утверждений.

Ответы на расчетные задачи (5-6) обязательно должны содержать подробное, пошаговое решение с объяснением логики и всех используемых формул. Просто числовой ответ без вывода будет считаться неполным.

---
### 1. Опишите трехсторонний протокол распределения ключей между парами участников с использованием третьей стороны.

 При описании протокола явно обозначьте роли всех трех сторон, назовите основные этапы (с указанием, кто, кому и что отправляет) и сформулируйте итоговый результат — какой ключ и между какими участниками устанавливается. 


### 2. Приведите формальные модели шифров.

Излагайте материал системно. Для моделей шифров укажите их компоненты и назначение. 


### 3. Приведите принципы построения поточных систем шифрования.

Вопросы 2 и 3: Излагайте материал системно. Для принципов поточных шифров — поясните, для чего нужен каждый принцип (стойкость, эффективность и т.д.). 

### 4. Приведите пример режима шифрования, в котором биективность всех шифрующих отображений базового режима не является необходимой для однозначного расшифрования криптограмм. Ответ обоснуйте. 

Важен именно обоснованный пример. Назовите конкретный режим, объясните, почему в нем биективность не требуется, и опишите механизм однозначного расшифрования.

### 5. Сколько 64-битовых блоков открытого текста искажается при расшифровании криптограммы симметричного блочного шифра, если в шифрованном тексте исказился один бит и используется режим гаммирования с обратной связью по шифртексту, в котором блоки открытого и шифрованного текста имеют длину 8 бит? Ответ обоснуйте.

Особое внимание уделите обоснованию. Кратко опишите логику работы режима CFB и покажите, как ошибка распространяется на блоки открытого текста. Проиллюстрируйте это для заданных размеров (64-битовые блоки открытого текста, 8-битовые блоки шифртекста). 

### 6. Однонаправленная хэш-функция принимает значения из множества двоичных n-мерных векторов. При каком n случайная пара сообщений составляет коллизию с вероятностью, не большей 10-9? Обязательно должен быть приведен ход решения.

Решение должно опираться на известную вероятностную модель (например, "парадокс дней рождений"). Четко запишите неравенство, выразите n и проведите вычисления с указанием всех промежуточных шагов.
